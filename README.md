A chess engine in 4,096 bytes of Python: 0x88 board, alpha-beta with a
transposition table, null-move pruning, late move reductions, quiescence
search over captures and promotions, killer and history move ordering, and a
tapered king evaluation. `main.py` is the whole engine and is packed from
`engine.src.py` with the kit's `makefun compress`.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
